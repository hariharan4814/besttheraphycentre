# The Best Therapy & Healing Centre - Mettupalayam

A modern, responsive web application for "The Best Therapy & Healing Centre" located in Mettupalayam. This website showcases natural healing services, treatments, and provides an easy way for patients to connect with the centre.

## 🌟 Features

- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.
- **Dynamic Treatment Pages**: Detailed pages for various treatments like Tera Care, Acupuncture, and Beauty Therapy.
- **Interactive UI**: Smooth animations, cursor effects, and interactive elements using Framer Motion.
- **Dark/Light Theme**: Built-in theme switching capability for better user experience.
- **SEO Optimized**: Includes meta tags, Open Graph tags, and Schema.org structured data for better search engine visibility.
- **Optimized Performance**: Lazy loading of pages for faster initial load times.
- **Contact Integration**: Easy-to-use contact forms and sticky call buttons for immediate reachability.
- **Image Gallery**: Visual showcase of the centre's facilities and treatments.
- **Testimonials**: Section to display patient feedback and success stories.

## 🛠️ Tech Stack

This project is built using a modern frontend stack:

- **Framework**: [React 18](https://reactjs.org/) with [Vite](https://vitejs.dev/) for fast development and building.
- **Language**: [TypeScript](https://www.typescriptlang.org/) for type safety and better developer experience.
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) for utility-first styling with modern design tokens.
- **UI Components**: Built with [Radix UI](https://www.radix-ui.com/) primitives (accessible, unstyled components).
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for powerful and performant animations.
- **Routing**: [React Router DOM](https://reactrouter.com/) for client-side routing.
- **Forms**: [React Hook Form](https://react-hook-form.com/) with [Zod](https://zod.dev/) for schema validation.
- **Icons**: [Lucide React](https://lucide.dev/) for consistent and beautiful iconography.
- **Toasting**: [Sonner](https://sonner.emilkowal.ski/) for stacking toast notifications.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd mettupalayam-healing-hub-main
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

### Running the App

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:8080` (or similar port).

### Building for Production

To build the application for production:

```bash
npm run build
```

This will create a `dist` directory with the optimized build.
